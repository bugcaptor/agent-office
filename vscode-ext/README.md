# Agent Office 로그 (VSCode 확장)

실행 중인 [agent-office](../) 데스크톱 앱에 붙어, 캐릭터(에이전트) 목록·상태·알림을
활동바 트리로 보여 주고 **세션 로그를 에디터에서 편하게 스크롤·검색**하게 하는 뷰어다.

정본 계획: `docs/vscode-character-extension-plan.md` (저장소 루트 기준)

## 무엇을 하는가

- **캐릭터 트리** — 앱의 control 서버(`/v1/list`, `/v1/notifications`)를 2초 간격으로
  폴링해 이름·역할·상태(작업중/유휴)와 대기 중 알림을 보여 준다. 알림 있는 캐릭터가
  위로 올라오고, 뷰 배지에 총 알림 수가 붙는다.
- **tail-follow 로그 문서** — 캐릭터를 펼쳐 세션 로그를 고르면 읽기 전용 가상 문서로
  열린다. 파일에 새 줄이 붙으면 자동으로 반영되고, **마지막 줄을 보고 있을 때만**
  끝으로 따라간다. 위로 스크롤해 읽는 중이면 절대 방해하지 않는다.
- **대용량 대비** — 기본으로 파일 끝에서 512KB만 읽고, 잘린 경우 첫 줄에 안내가 붙는다.
  에디터 제목줄의 **전체 불러오기** 버튼으로 처음부터 볼 수 있다.
- **알림** — 알림 항목을 클릭하면 전체 메시지를 띄우고 "지우기"로 앱의 `/v1/clear`를
  호출한다. 이것이 이 확장의 유일한 쓰기 동작이다.

## 앱 쪽 준비

이 확장은 앱을 조종하지 않고 **읽기만** 한다. 앱에서 두 가지가 켜져 있어야 한다.

1. **CLI 제어**(`cliEnabled`) — 앱 설정에서 켠 뒤 **승인**까지 눌러야 토큰이 발급된다.
   확장은 `ctl`과 동일하게 `<app_data>/control-port`·`control-token`을 읽는 또 하나의
   클라이언트일 뿐이며, 토큰은 메모리에만 두고 설정·로그에 남기지 않는다.
   확장이 `cliEnabled`를 대신 켜 주는 일은 없다(앱의 권한 상승 차단 설계 존중).
2. **세션 로그 기록**(`sessionLogEnabled`, 기본 켜짐) — `<app_data>/session-logs/v1/`에
   로그가 쌓여 있어야 열람이 가능하다.

앱이 꺼져 있거나 미승인 상태여도 트리는 `profiles.json` 기반 목록으로 강등되어
**로그 파일 열람은 계속 가능**하다. 미연결 사유(앱 꺼짐 / CLI 제어 OFF / 미승인 /
승인 취소)는 트리 첫 줄에 그대로 표시된다.

## 설치·실행 (개발)

```bash
cd vscode-ext
npm install
npm run compile     # tsc -p ./  → out/
npm test            # vitest (순수 모듈 유닛 테스트)
```

VSCode로 `vscode-ext/` 폴더를 열고 **F5**를 누르면 확장 개발 호스트가 뜬다
(`npm: watch` 태스크가 자동으로 걸린다). 활동바의 Agent Office 아이콘을 열면 된다.

## 설정

| 설정 | 기본값 | 설명 |
|---|---|---|
| `agentOffice.appDataDir` | `""` | 앱 데이터 폴더. 비우면 `AGENT_OFFICE_APP_DATA` → OS 기본 경로 순으로 자동 발견 |
| `agentOffice.pollIntervalMs` | `2000` | 포커스 중 폴링 간격(ms). 백그라운드·앱 꺼짐 시 10초로 늘어난다 |
| `agentOffice.logTailKb` | `512` | tail 문서가 파일 끝에서 읽는 크기(KB) |
| `agentOffice.notifyToast` | `false` | 새 알림을 VSCode 토스트로도 띄운다 |

## 제약

- **로컬 전용.** 로그 파일 직접 읽기와 `127.0.0.1` control 서버 모두 앱과 같은 기계의
  로컬 VSCode 창에서만 성립한다. Remote SSH 창 지원은 앱에 로그 라우트가 생기는
  V3 과제다(계획 문서 §3 V3).
- **실시간 터미널 미러가 아니다.** 세션 로그는 앱이 2초 간격 tail + TUI 재그리기 축약을
  거쳐 저장하는 "정리된 대화록"이다. 스크롤·검색에는 유리하지만, 한 글자 단위 실시간성이
  필요한 장면은 앱 터미널을 쓴다.
- **파일명 규약 의존.** `<YYYYMMDD-HHMMSS>-<sid8>.log` 파싱은
  `src-tauri/src/session_log/store.rs`가 정본이다. 그쪽이 바뀌면 이 확장도 따라가야 한다.
